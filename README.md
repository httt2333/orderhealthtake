# 安心药盒 · V1.5 老人独立使用版

这个 Web 原型既支持老人自行录入并设置提醒，也保留家属协助进行新旧资料比对的可选路径。

## 启动

无需安装额外依赖，Node.js 18+：

```bash
npm run dev
# 打开 http://localhost:4173
npm test
```

也可直接打开 `安心药盒_V1.5_单文件预览.html`（本地浏览器的文件权限可能限制语音识别；建议使用本地服务器）。

## 主流程

**老人独立操作**：`#/elder/home` → `#/elder/setup`（拍照留作本地参考 / 自己填写 / 加载虚构示例）→ `#/elder/edit-plan` → `#/elder/reminders` → `#/elder/today` → 本人记录“已服用”或撤销。全程无需进入家属页面。

**语音**：`#/elder/start` 通过浏览器 SpeechRecognition 识别“添加药单 / 今天用药 / 提醒”等意图；录入页“药品名称、每次数量”提供独立语音输入按钮。浏览器支持语音合成时可朗读今日计划和试听提醒，麦克风无权限可手动操作。

**提醒**：页面保持打开且处于可见状态时，按本机时间每30秒检查计划，命中该分钟时提示一次。用户主动批准浏览器通知后，提示可通过系统通知呈现（仍依赖页面运行）。提供试听。没有推送服务器，因此**关闭页面或浏览器后不会稳定持续提醒**，不得宣传为可靠的后台药物提醒服务。

**拍照**：使用设备相机选择照片并本地预览；**尚无真正 OCR/LLM**，用户需对照资料自行填写计划。页面使用简单标签，不向用户展示冗长技术说明；README 保留能力边界。

**家属协助**：原 `#/family/dashboard` 等页面继续支持 Mock 药单信息校对及差异对比，没有账户系统也没有真实跨设备共享。

## 数据边界

- 原型使用虚构药物示例（模拟药A/C）；实际药物名称、数量与时间只能从使用者已有的医嘱/药单原样录入，AI不会制定、修改或决定处方。
- “已服用”是用户自述记录，不是传感器证明。
- 使用浏览器 `localStorage` 在本机保存安排和记录，无加密、账号或后端备份；**不要用它储存真实患者的敏感健康资料或将原型用于临床决策**。
- 真实模型推理、后台推送、OCR、服务端用户鉴权、合规存储与医疗流程校验均尚未接入。
