# 安心药盒 · V1.5 老人独立使用版

这个 Web 原型既支持老人自行录入并设置提醒，也保留家属协助进行新旧资料比对的可选路径。

## 启动

无需安装额外依赖，Node.js 18+：

```bash
npm run dev
# 打开 http://localhost:4173
npm test
```

也可直接打开 `安心药盒_V1.5_单文件预览.html`（本地浏览器的文件权限可能限制语音识别；建议使用本地服务器）。

## 主流程

**老人独立操作**：首页 → 添加用药 → 拍摄／选择自己正在用的药盒照片 → 依据药单填写药名、数量、时间 → 对照照片和药单核对 → 保存 → 今天用药看大照片、逐项听安排、记录服药。

药盒照片与一条用药安排绑定，压缩为最长边 640px 的 JPEG 后保存在当前浏览器。照片缺失或看不清时可补拍；虚构示例没有真实药盒照片，会明确显示缺图。拍照不进行 OCR 或自动药物识别。

**朗读**：每项提供“听这次怎么吃”，读取该项已核对的时间、药名、每次数量；再次点击重读，可随时停止，并显示准备、播放、结束或失败状态。照片可点开放大，保留同一项的朗读和返回入口。录入核对页也可以试听。浏览器语音合成是实际实现，音色和可用性取决于设备。语音任务输入仍采用浏览器识别与规则匹配，未接入生成式 AI。

**提醒**：网页保持打开且可见时，每30秒检查一次时间；关闭网页或切到后台后不保证提醒。通知授权不能替代后台推送服务。

“记不清”是服药后的辅助异常入口，只引导查看药单或咨询医生、药师。产品说明、Demo 运行步骤和复盘见 `挑战交付/`。

**家属协助**：原 `#/family/dashboard` 等页面继续支持 Mock 药单信息校对及差异对比，没有账户系统也没有真实跨设备共享。

## 数据边界

- 原型使用虚构药物示例（模拟药A/C）；实际药物名称、数量与时间只能从使用者已有的医嘱/药单原样录入，AI不会制定、修改或决定处方。
- “已服用”是用户自述记录，不是传感器证明。
- 使用浏览器 `localStorage` 在本机保存安排和记录，无加密、账号或后端备份；**不要用它储存真实患者的敏感健康资料或将原型用于临床决策**。
- 真实模型推理、后台推送、OCR、服务端用户鉴权、合规存储与医疗流程校验均尚未接入。

## 验证

`npm test`：50项代码测试通过（含新增自主入口及提醒列表测试）。真实手机语音/通知体验和浏览器视觉自动化仍待人工验收。

**全页语音操作**：底部固定圆形麦克风，在任意页面直接点击说出任务；再点取消。准备、正在听、结束或失败会明确反馈。没有自动录音，真实收音依赖浏览器权限。

语音指令识别成功后会先通过浏览器语音合成回应目标任务，再打开对应页面；再点圆形按钮可取消回应。没有语音合成能力时直接打开并用文字反馈，回应播放失败或超时也不会永久阻塞导航。
