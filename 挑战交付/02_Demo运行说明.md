# Demo 运行说明

需要 Node.js 18+，无需安装第三方依赖。项目目录运行 `npm run dev`，打开 `http://localhost:4173/#/elder/home`。

## 主流程

1. 添加用药 → 拍药盒，自己填写。
2. 选择自己提供的测试图片，按虚构安排填写药名、数量、时间。图片不会自动识别。
3. 下一步核对照片与内容，可试听，再确认保存。
4. 今天用药查看照片，点照片进入大图页；点“听这次怎么吃”播放对应安排，可重听或停止。播放准备、结束或失败都有状态反馈。
5. 刷新页面确认照片保留；补拍时核对是否仍对应同一药物。
6. 记录已服用或记不清；可撤销。

示例安排没有真实药盒照片，会显示缺图。请补选测试照片，不能把通用图标当作自己的药盒。

## 实现情况

本地照片压缩和保存、绑定核对、逐项朗读、记录均已实现。拍摄相机能否直接打开、中文音色和权限体验取决于设备；浏览器无朗读能力时保留页面上的同一份安排。

照片最长边压缩至640像素后保存在本浏览器 localStorage；无法保存时会报错而不显示保存成功。没有云端照片上传、OCR、生成式AI或后台推送。

页面源码在 `src/app.js`，样式在 `styles.css`；单文件版为 `安心药盒_V1.5_单文件预览.html`。建议本地服务器运行，文件模式权限可能受限。
