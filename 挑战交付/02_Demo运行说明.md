# Demo 运行说明

## 环境

- Node.js 18 或更新版本
- 不需要安装第三方依赖

## 启动

在项目目录运行：

```bash
npm run dev
```

浏览器打开 `http://localhost:4173/#/elder/home`。

## 演示步骤

1. 在首页选择“今天用药”。
2. 空列表时选“试用示例”，进入虚构的今日安排。
3. 对一项选择“已服用”，观察状态变化；再次选择可撤销。
4. 对另一项选择“记不清”，观察“不确定”状态和查看药单／询问医生或药师的提示。
5. 撤销不确定记录，确认状态回到“尚未记录”。
6. 也可以打开“语音帮我操作”，说“我不确定是否服过”。浏览器识别成功后会进入今天用药页；无需允许麦克风也可以使用页面上的按钮。

## 源码位置

- 页面与交互：`src/app.js`
- 今日用药页面样式：`styles.css`
- 确定性药单比较逻辑：`src/domain.js`
- 单文件预览：`安心药盒_V1.5_单文件预览.html`

## 演示边界

示例药物完全虚构。语音使用浏览器自带识别和本地关键词规则，不是生成式 AI。用户手动输入的信息只存于当前浏览器的 localStorage。提醒在网页关闭后不能保证触发。演示不判断是否应该补服，也不生成或修改处方。
